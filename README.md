# Лабораторная работа №1 — Веб-программирование

Веб-приложение для проверки попадания точки в заданную область на координатной плоскости.

**Вариант:** 12649.

## Возможности

- Ввод координат точки и выбор одного или нескольких значений радиуса.
- Проверка попадания для каждого выбранного значения R.
- Отрисовка области и проверенных точек на Canvas.
- Проверка корректности введённых данных с выводом сообщений об ошибках.
- Таблица результатов с координатами, радиусом, результатом и временем проверки.
- Сохранение истории в `localStorage` между перезагрузками страницы.
- Очистка истории проверок.

## Входные данные

| Параметр | Допустимые значения | Способ ввода |
| --- | --- | --- |
| X | −3, −2, −1, 0, 1, 2, 3, 4, 5 | Выпадающий список |
| Y | От −5 до 3 включительно | Текстовое поле |
| R | 1, 2, 3, 4, 5 | Флажки, можно выбрать несколько |

Для дробной части Y можно использовать точку или запятую, например `1.25` или `-2,75`. Перед проверкой нужно выбрать хотя бы одно значение R.

## Область попадания

Область состоит из трёх фигур. Границы входят в область.

| Часть области | Условия попадания |
| --- | --- |
| Четверть круга в I четверти | `x ≥ 0`, `y ≥ 0`, `x² + y² ≤ R² / 4` |
| Треугольник во II четверти | `−R/2 ≤ x ≤ 0`, `0 ≤ y ≤ x + R/2` |
| Прямоугольник в IV четверти | `0 ≤ x ≤ R`, `−R/2 ≤ y ≤ 0` |

Точка попадает в область, если выполняются условия хотя бы одной из фигур. На графике попадания отмечаются зелёным, промахи — красным.

## Технологии

- **HTML5** — структура страницы и форма ввода.
- **CSS3** — оформление и компоновка с помощью Flexbox.
- **JavaScript** — валидация, проверка попадания и работа с историей.
- **Canvas API** — отрисовка координатной области и точек.
- **localStorage** — хранение истории в браузере.
- **BigInt** — проверка попадания с точным представлением введённой десятичной координаты Y.

Приложение работает полностью в браузере. HTML, CSS и JavaScript находятся в файле [index.html](index.html).

## Запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/AlexPer777/lab1_web.git
   cd lab1_web
   ```

2. Откройте `index.html` в современном браузере с поддержкой BigInt.

Также страницу можно запустить через локальный HTTP-сервер, если установлен Python 3:

```bash
python3 -m http.server 8000
```

После запуска откройте [http://localhost:8000](http://localhost:8000).

## Использование

1. Выберите X и введите Y.
2. Отметьте одно или несколько значений R.
3. Нажмите **«Проверить точку»**.
4. Посмотрите результат в таблице и на графике.

При выборе нескольких радиусов в таблицу добавляется отдельная запись для каждого R. Масштаб графика соответствует наибольшему выбранному радиусу.

Кнопка **«Очистить историю»** удаляет результаты из таблицы, с графика и из `localStorage`. История хранится отдельно для каждого адреса сайта и браузера.
